# Use Cases: SE-BahnMap
## Use Case 01:
- Live-Positionen und Bewegungen von Regionalzügen, Bussen und Fähren rund um den Bodensee ohne Neuladen der Seite anzeigen.
## Use Case 02:
- Spezifische Betriebsdaten fahrender Fahrzeuge wie die aktuelle Verspätung oder den nächsten Fahrplan Halt einsehen.
## Use Case 03:
- Erkennen, auf welchen Strecken häufig Verspätungen auftreten.
## Use Case 04:
- Die aktive Karte filtern, um nur einen einzelnen Fahrzeugtyp anzuzeigen.
## Use Case 05:
- Automatische Wiederherstellung der nahtlosen Echtzeit-Kartenaktualisierung bei unerwartetem Netzwerkabbruch.
